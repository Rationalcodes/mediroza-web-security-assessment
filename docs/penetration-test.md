# Mediroza General Hospital
## Web Application Penetration Testing — Technical Case Study

> **Authorized Educational Security Assessment**

---

## 1. Engagement Overview

This project was completed as part of the NetworkWalks web application
penetration-testing exercise.

The assessment was performed against the authorized Mediroza General
Hospital training environment.

The engagement was structured as a five-day black-box penetration test
with four defined milestones:

1. Initial Access
2. Data Extraction
3. Critical Data Exposure
4. Professional Penetration Testing Report

The objective was to approach the application from an external
attacker's perspective, identify vulnerabilities, demonstrate their
impact within the authorized environment, and document the findings
professionally.

## 3. Rules of Engagement

The exercise provided the following restrictions:

- Testing was limited to the target domain.
- No social engineering was permitted.
- No denial-of-service testing was permitted.
- Testing outside the agreed scope was prohibited.
- Findings were to remain confidential until the designated reveal
  session.

All testing documented in this case study was performed within the
authorized training environment.

> **Important:** The techniques described in this repository must never
> be applied to systems without explicit written permission from the
> system owner.
